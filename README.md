# Jogo-7-a-0

------------------------  Descrição  -----------------------

Simulação de escalação das equipes de todas as épocas.
O 7a0 junta as maiores seleções de todas as Copas do Mundo — de 1950 a 2026 — num só lugar.
Você sorteia seleções, monta um time dos sonhos cruzando gerações que nunca se enfrentaram e simula um torneio inteiro pra ver se ele faz o 7 a 0.
É um jogo de futebol, memória e montagem — leve de pegar, viciante de repetir.

------------------------  Publico alvo  -----------------------

Amantes, saudosistas, e entusiastas.

------------------------  Principais funcionalidades  -----------------------

Por trás do jogo há uma base curada de futebol das Copas do Mundo:

52 seleções que disputaram Copas, de potências a zebras históricas.
20 Copas, de 1950 a 2026 — incluindo seleções extintas (URSS, Iugoslávia, Tchecoslováquia).
~250 escalações e ~5.700 jogadores, cada um com posição, número, força e selo de lenda.
Cada elenco é montado a partir de quem de fato vestiu a camisa naquela Copa — a matéria-prima do seu time.
